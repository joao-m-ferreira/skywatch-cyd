Fourth release of **skywatch-cyd**.

## New
- **0.96" OLED version.** The same firmware now runs on a 128x64 monochrome SSD1306 OLED, as plain text:
  callsign, type, airline, altitude, speed, distance and heading. No 3D model, photo or touch; the BOOT
  button shows the next plane. Two builds: `oled96` (an OLED module on GPIO 21/22) and `oled96-onboard`
  (boards with the OLED built in, GPIO 5/4). Other pins: `set i2c <sda> <scl>`. Not tested on hardware.
- **Download firmware** in the web portal: every board now has a Download button beside Install.

## Boards
| Board | `<board>` | Status |
|---|---|---|
| Cheap Yellow Display 2.8" (ILI9341) | `cyd` | tested on real hardware |
| Cheap Yellow Display 2.8", two USB ports (ST7789) | `cyd-st7789` | not tested on hardware |
| 3.5" "big CYD" (ST7796) | `cyd35` | experimental |
| Waveshare ESP32-S3-Touch-AMOLED-1.8 | `amoled18` | emulator only |
| ESP32 + 0.96" OLED module | `oled96` | not tested |
| ESP32 with a built-in 0.96" OLED | `oled96-onboard` | experimental |

Flash from the [web portal](https://joao-m-ferreira.github.io/skywatch-cyd/) or with the `-merged.bin` for
your board at `0x0` (`--chip esp32s3` for the AMOLED board). Verify the downloads against `SHA256SUMS`.
