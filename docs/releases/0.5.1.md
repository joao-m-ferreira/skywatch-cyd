Sixth release of **skywatch-cyd**: the ESP8266 board gets the network features.

## New
- **ESP8266 web page, JSON API, MCP server and mDNS.** The `esp8266-oled` build now serves the same web page (planes and
  settings), JSON API and read-only MCP server as the ESP32 builds, announces `skywatch.local` and `_mcp._tcp`, and has the
  same access token. It runs the same code as the ESP32 builds, with smaller limits (2 KB request bodies, a 4 KB tool result)
  and without the WiFi setup access point. See [network interfaces](../network-interfaces.md).
- To make room on the 80 KB chip, the serial help text and the settings page stylesheet now live in flash, and the TLS receive
  buffer is 6 KB; a fetch that finds too little memory reports it instead of crashing. If a board reports "Not enough memory for
  TLS", `set web off` and `set mcp off` give the memory back.
- The HTTP Basic login no longer depends on mbedTLS (one decoder for both chips, host-tested).

## Honest status
Verified on a real ESP8266 board that it starts the server, announces itself and keeps fetching planes and routes. The HTTP
interfaces have not been used from another computer on that board yet; on the ESP32 they are tested in the emulator.

## Boards
Unchanged from 0.5.0 (nine boards). Flash from the [web portal](https://joao-m-ferreira.github.io/skywatch-cyd/) or with the
`-merged.bin` for your board at `0x0`; the ESP8266 image is a single file at `0x0` for install and update. Verify the downloads
against `SHA256SUMS`.
