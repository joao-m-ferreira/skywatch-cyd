First release of **skywatch-cyd**: a standalone nearby-flights display for the ESP32-2432S028
("Cheap Yellow Display"). No server needed: the board talks to the internet itself.

## What it does
- Shows the aircraft within your radius (default 40 km), one at a time, as a carousel (touch to skip).
- Callsign, airline, type, altitude, speed/track, distance and bearing, a compass with the direction
  of travel, and the **route** (origin > destination) when known.
- A shaded **3D model** of the aircraft type (~110 types) in the airline's livery, or a **photo** of
  that exact aircraft from planespotters.net (credited on screen) when one exists.
- The back **RGB LED** shows the airline's colour; airlines with two real colours fade between them.
- **Night mode** (screen and LED off on a schedule, touch to wake) and **IP-based location**
  (or a fixed one). Settings are changed over USB serial and kept in flash.
- WiFi and hardware watchdogs, automatic restarts if the board gets stuck or runs low on memory.

## Install
You need `esptool` (`pip install esptool`) and a USB cable. Find the port first
(macOS `/dev/cu.wchusbserial*` or `/dev/cu.usbserial*`, Linux `/dev/ttyUSB0`, Windows `COM3`).

**Fresh board or first install** (one file; this also erases saved settings):
```
esptool.py --chip esp32 --port <port> --baud 460800 write_flash 0x0 skywatch-cyd-0.1.0-merged.bin
```
**Update an installed board** (keeps your WiFi and settings):
```
esptool.py --chip esp32 --port <port> --baud 460800 write_flash 0x10000 skywatch-cyd-0.1.0-firmware.bin
```
Then open a serial terminal at **115200 baud** and type `help`:
```
set ssid <your WiFi>      set pass <password>      show      status
```
The default location is found from your public IP (geojs.io, city level). Fix it with
`set location static <lat> <lon>`. Verify the downloads against `SHA256SUMS`.

## Good to know
- Data: adsb.fi open data (personal, non-commercial use), adsbdb routes, planespotters.net photos.
  planespotters.net requires a contact in each request: set yours with `set contact <email>`.
- Routes are general per-callsign data and can be wrong or missing.
- The IP lookup sends your public IP to geojs.io; use a static location to avoid it.
- Not included: airline logos, AI-painted images, weather.
- Built for the **ESP32-2432S028R** (resistive touch, ILI9341). Capacitive variants use other pins.
